### Sistema Inventario ###

# ¿Qué hace el proyecto?
Es un sistema de registro y consulta de productos. En este se pueden registrar el nombre y cantidad de los productos y se muestran el ID, nombre, cantidad, fecha y hora de los produtcos registrados

# ¿Qué tecnologías utiliza?
- PHP 8.2
- Apache 2.4
- CSS
- MariaDB (MySQL)


# ¿Qué se necesita instalar?
- Visual Studio Code
- XAMPP (incluye php y apache)
- Navegador web de preferencia

# ¿Comó se configura y ejecuta?
1.- Se crea la base de datos
2.- posteriormente se ejecuta el script 'base_datos.sql' usando la base de datos antes creada
3.- Se descomprime el archivo inventario.zip en la carpeta htdocs de  la carpeta de XAMPP
3.- En el archivo config/conexion.php de este sistema se colocal las credenciales correctas
4.- En un navegador se coloca en la URL localhost/inventario
